# codeLess v3.4.1

A visual polish, editor selection parity, and cross-platform CI reliability release.

## New

- **Seti file icons everywhere**: Embedded the VS Code Seti UI icon font and mapping (`SetiIconTheme`, `seti.ttf`) and wired file-type icons across the Explorer tree (`AvaloniaExplorerTree`, `CodeLessExplorerTree`), editor tabs, breadcrumbs, Open Editors list, Source Control (SCM) changed files, Problems panel entries, Quick Open / location pickers (`AvaloniaCommandPaletteOverlay`), and AI chat composer context pills.
- **VS Code Dark Modern, Dark+, Light Modern & Light+ themes**: Added VS Code's **Dark Modern** (now the default theme), **Dark+**, **Light Modern**, and **Light+** themes (`VsCodeDefaultThemes`, `StudioTheme`, `TextMateTheme`), along with pixel-rounded glyph draw coordinates (`Math.Round`), `UseLayoutRounding`, and `TextRenderingMode.SubpixelAntialias` on `AvaloniaVirtualEditorCanvas`.

## Fixed

- **Syntax highlighting (C# numeric literals & Python f-strings)**: Truncated capture sub-tokenization line text at the capture end in `TextMateTokenizer.HandleCaptures` so `$`-anchored capture patterns (such as C# and Go numeric literals) match instead of falling through to `invalid.illegal.numeric.cs`; and stripped balanced `(?#...)` Oniguruma comment groups across newlines before `#` line-comment stripping in `OnigurumaTranslator.StripExtended` (`TextMateRegex`) so Python f-string (`f"...{expr}..."`) literal rules compile and highlight properly.
- **Line & word boundary selection parity (`Cmd+Shift+Right/Left`, `Shift+End/Home`)**: `Cmd+Shift+Right/Left` and `Shift+End/Home` (`cursorEndSelect` / `cursorHomeSelect`) now match VS Code's `_moveToLineEnd` and `_moveToLineStart` semantics in both UIs (`AvaloniaVirtualEditorCanvas` and `CodeLessVirtualCanvas`)—stopping at the wrapped visual row boundary first (with row-end caret affinity) before advancing to the model line boundary, toggling between the first non-whitespace column and column `0` (`EditorWrapNavigation.FirstNonWhitespaceColumn`, moving directly to column `0` on all-whitespace lines), preserving forward and backward selection anchors, merging overlapping multi-cursor selections into their union range (`EditorWrapNavigation.NormalizeAndMergeCarets`), and stepping cleanly across UTF-16 surrogate pairs and folded regions. Added `Ctrl+A`/`Ctrl+E` (`cursorLineStart`/`cursorLineEnd` and `cursorLineStartSelect`/`cursorLineEndSelect`) model-line movement on macOS, and registered all `cursor*Select` and word-navigation commands (`cursorHomeSelect`, `cursorEndSelect`, `cursorTopSelect`, `cursorBottomSelect`, `cursorWordLeft`, `cursorWordLeftSelect`, `cursorWordEndRight`, `cursorWordEndRightSelect`) in `DefaultCommands` and `KeybindingManager`.
- **Windows & Linux keymap, file-locking & shell reliability**: Fixed per-platform default keybindings (`KeybindingManager` platform-aware defaults) and duplicate shortcut collisions in `DefaultCommands`; eliminated a 5,000 ms stall on Windows caused by `CrossProcessFile.ReadModifyWrite` attempting to delete `.lock` files before closing the lock `FileStream`; wrote long (`> 8,000` char) Windows PowerShell commands in `LlmAgentEngine.Terminal.cs` to a temporary `codeless-cmd-<guid>.ps1` script executed via `-File`; skipped `WindowsApps` stub shims during language-server binary discovery (`LanguageServerRegistry.FindInDirs`); and fixed `IdeSettingsWatcher` / `FileSystemWatcher` race conditions and `WeakReference` window lifecycle cleanup.
- **Windows `netstandard2.0` build**: Guarded `WindowsIdentity.GetCurrent()` in `ApplicationSession.cs` with `#if !NETSTANDARD2_0` so the `netstandard2.0` target of `codeLess.Core` compiles cleanly in Release solution builds without extra package dependencies.
- **False syntax errors eliminated**: Matched VS Code's live diagnostics model in `LlmHarnessAndAgentEngine.ComputeBufferAstAndDiagnostics` by removing heuristic bracket-imbalance, `TODO`, and `eval`/`exec` squiggles and emitting live non-LSP diagnostics only for JSON / JSONC via an exact recursive-descent validator (`SyntaxVerifier.TryValidateJsonc` / `ValidateJsoncDiagnostics`, supporting `//`, `/* */`, and trailing commas); upgraded `EditorBracketCache` (`BracketLexProfile`) for C# 12 raw/verbatim/interpolated strings with nested quotes, Python 3.12 nested f-string quotes, JS/TS `${...}` templates and `/.../flags` regex literals, JSX text apostrophes and prose parentheses, Go raw backtick strings ending with `\`, Rust lifetimes and `r#"..."#` raw strings, HTML/XML (`MarkupText`), and POSIX shell (`ShellMode`); unified `SyntaxVerifier` onto `VerifyBracketsWithProfile`, lazy-loaded Roslyn (`VerifyCSharpSyntaxWithRoslyn`, `LanguageVersion.Preview` syntax errors only), and Python ≥ 3.12 `py_compile` gating; and added Python 3.12 PEP 695 `[T]` type-parameter support in `python.tmLanguage.json.gz`.

# codeLess v3.4.0

A major feature and performance release bringing full VS Code multi-window/multi-instance parity (`W1`), data-driven keybindings and settings (`W3`), a complete `sst/opencode`-derived autonomous agent harness (`M1–M9d` including local stdio MCP servers, custom Markdown agents/commands, `@file` fuzzy completion, and per-turn `/undo` & `/redo`), 100% audited editor, workbench, cross-cutting QA, and file/hot-exit parity (`W5`, `W6`, `W7`, `W10`), and a 74%–99% reduction in in-process managed memory usage (`W4`, `docs/MEMORY.md`).

## Highlights in v3.4.0

### 1. Multi-Window & Multi-Instance Parity (`W1`)
- **Single-instance IPC forwarding (`ApplicationSession` / `NamedPipeIpcTransport` / `AvaloniaWindowManager`)**: Launching a second `codeLess` process forwards CLI arguments over a per-user named pipe (`NamedPipeIpcTransport`) to the primary instance and exits cleanly; if a folder or file is already open in an existing window, that window is focused instead of duplicating it.
- **VS Code CLI flags (`ApplicationSession.ProcessArgs`)**: Full support for `<folder|file>`, `-n` / `--new-window`, `-r` / `--reuse-window`, `-g` / `--goto <file:line[:col]>`, `-d` / `--diff <left> <right>`, `-a` / `--add <folder>`, `-w` / `--wait` (blocks caller until the target tab or window closes), `--new-instance`, `--user-data-dir <dir>`, and `--workspace <dir>`.
- **Window session restore (`window.restoreWindows` & `WorkspaceSessionStore`)**: Restores open windows, bounds, maximised/fullscreen state, split editors, and tabs on startup (`all`, `one`, or `none`), with cascading placement for new windows and macOS dock stay-alive semantics when the last window closes.
- **Live cross-window settings sync (`IdeSettingsWatcher`)**: Editing settings or themes in one window or on disk propagates live to all open windows without clobbering per-window layout or MRU state.

### 2. VS Code Keybindings & Settings (`W3`)
- **Data-driven `KeybindingManager` & `WhenParser`**: Every shortcut in `DefaultCommands` (`CommandRegistry.AllCommands`) is evaluated through boolean `when`-clauses (`editorTextFocus`, `terminalFocus`, `suggestWidgetVisible`, `inQuickOpen`, `findInputFocussed`, `inDebugMode`, etc.) with multi-chord dispatch (`Cmd/Ctrl+K ...`) and `TerminalCommands.CommandsToSkipShell` pass-through (`DataDrivenRegistryTests.AllRegistryDefaults_AreDispatchable`, `DataDrivenRegistryTests.KeybindingsDocMatchesCode`).
- **Keyboard Shortcuts editor (`Cmd/Ctrl+K Cmd/Ctrl+S`) & `keybindings.json`**: Searchable shortcut table with live conflict detection, key-recording modal, and round-trip persistence to `keybindings.json` (preserving JSONC comments and `-command` unbind entries).
- **Layered `settings.json` (JSONC, `VscodeSettingsManager`)**: Two-way synchronisation between the Settings UI (`Cmd/Ctrl+,`) and `settings.json`, plus workspace overrides in `.vscode/settings.json`.

### 3. `opencode`-Derived Agent Harness (`M1–M9d`)
- **14 built-in agent tools (`LlmHarnessAndAgentEngine.Tools`, guarded by `HarnessDocsAuditM8Tests.HarnessDocToolTableMatchesCode`)**: `read_file` [alias `read`] (0-based `offset` or 1-based `start_line`, default `limit` 2,000 lines, 2,000-char line cap, `BinaryDetector` guard, Levenshtein `MissingFileSuggestions`), `write_file` [alias `write`], `edit_file` [alias `edit`] (9-stage fuzzy `EditReplacers` cascade + `FileTimeTracker` read-before-edit guard), `multiedit` (atomic all-or-nothing batch edits with `FileTimeTracker` read-before-edit guard), `list_dir` [alias `list`], `grep_search` [alias `grep`], `glob`, `run_terminal` [aliases `run_command`, `bash`] (30,000-character head+tail truncation), `get_diagnostics`, `ast_outline`, `todowrite`, `todoread`, `webfetch` (HTML-to-Markdown/text via `LedgerHttp` / `NetworkLedger`), and `task` (depth-1 read-only subagent, `MaxSubagentIterations = 6`, optional `subagent_type`).
- **Plan vs. Build modes & `AgentPermissions`**: Switch between `Build`, `Plan`, and custom primary agents from the chat header or with `Tab` in the chat input (`AgentUiParity.CycleBuildPlanMode`); `Plan` mode denies all file edits (`write_file`, `edit_file`, `multiedit`) and restricts `run_terminal` to read-only inspection commands, with configurable `RequireAgentToolApproval`, `AgentPermissionEdit`, `AgentPermissionWebfetch`, `AgentPermissionBash`, and `AgentPermissionMcp`.
- **Resilience, context & diagnostics (`M4`, `M5`, `M7b`, `M7c`)**: Native OpenAI (`tools` / `tool_calls`) and Anthropic (`tool_use` / `tool_result`) streaming function-calling (`codeless.agent.nativeToolCalling`, `NativeToolCalling`) with automatic text-mode fallback, exponential backoff (`ApiRetryHandler`) honoring `retry-after-ms` / `retry-after`, 3-strike doom-loop detection, automatic context compaction (`/compact`, `AgentContextBuilder.PruneHistory`), hierarchical rules discovery (`AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md`, `.cursorrules`, `.codelessrules`, `.codeless/instructions.md`), and post-edit LSP `<file_diagnostics>` feedback (`LspDiagnosticsProvider`).
- **Local stdio MCP servers (`M9a`, `McpStdioClient`, `McpServerManager`, `McpConfigLoader`)**: Reads `codeless.mcp` server definitions from user `settings.json` and workspace `.vscode/settings.json` (workspace wins); implements newline-delimited JSON-RPC 2.0 over stdio (`initialize`, `notifications/initialized`, `tools/list`, `tools/call`) with request timeouts and stderr capture; exposes tools as `<server>_<tool>` in both native tool calling and text mode with default `"ask"` permission; starts servers lazily on first turn tool request and stops all child processes (`McpServerManager.StopAll`) on workspace change and window close (`McpStdioM9aTests`).
- **Custom Markdown agents & slash commands (`M9b`, `CustomAgentAndCommandRegistry`, `CustomAgentDefinition`, `CustomCommandDefinition`)**: Discovers `.codeless/agent/*.md`, `.opencode/agent/*.md`, and `<settingsDir>/agent/*.md` (and `command/*.md`) with YAML frontmatter (`description`, `model`, `temperature`, `tools`, `permission`, `mode: primary|subagent`) and mtime+size caching (`GetOrParseAgentFile`, `GetOrParseCommandFile`); includes custom primary agents in `Tab` mode cycling, selects custom subagents in `task` via `subagent_type`, and expands `/name args` templates (`$ARGUMENTS`, `$1..$9`, `@file` includes, and `` !`cmd` `` behind `run_terminal` permission; `CustomAgentsCommandsM9bTests`).
- **`@file` fuzzy mentions in chat input (`M9c`, `ChatAtMentionCompleter`)**: Typing `@` in `ChatPromptInput` (`MainWindow.UpdateChatAtMentionPopup` / `AcceptSelectedChatAtMention` and WinForms `CodeLessMainForm`) opens fuzzy file completion reusing `QuickOpenFileIndex` and attaches the selected file's content with `read_file` caps (`2,000` lines, `2,000` chars/line, `50 KB` bytes, and `BinaryDetector.IsBinaryFile` guard; `ChatFileMentionsM9cTests`).
- **Per-turn `/undo` & `/redo` (`M9d`, `StagedTurnHistory`, `StagedTurnSnapshot`, `AgentTurnCheckpointStore`)**: Every agent turn that stages changes records a `StagedTurnSnapshot`; typing `/undo` (or clicking `TurnRevertButton` `"↺ Revert"` on the assistant turn card in `AvaloniaAgentFeedControl`) restores `StagedFileContents` and active `AgentChangeSet` proposals (`MainWindow.HandleSlashUndoAsync`) to the pre-turn state without touching disk, `/redo` (`MainWindow.HandleSlashRedoAsync`) re-applies it, and turns already applied to disk revert/redo via `AgentTurnCheckpointStore` (`UndoAgentTurnAsync` / `RedoAgentTurnAsync`) with confirmation (`PerTurnUndoRedoM9dTests`).

### 4. Editor, Workbench, Cross-Cutting QA & Regression Hunt Parity (`W5`, `W6`, `W7` & `W11`)

### 5. Hot Exit, External File Changes, Encodings & Large/Binary File Robustness (`W10`)
- **Hot exit (`HotExitService`, `files.hotExit`: `off` | `onExit` | `onExitAndWindowClose`)**: Atomically backs up dirty file and untitled buffers under `<settingsDir>/Backups/<workspace-hash>/` using a single shared 1 s debounced timer (`ScheduleHotExitBackup` / `FlushPendingHotExitBackups`) that stops when idle, restores dirty tabs with content, cursor, selection, and scroll (`RestoreHotExitBackups`), deletes backups on Save/Revert/Don't Save, and flags `HasExternalDiskConflict` if the file was modified on disk while closed (`FilesHotExitParityW10Tests`, `docs/FILES_PARITY.md`).

- **Encodings, EOL & save participants**: Detects and losslessly round-trips `UTF-8`, `UTF-8 BOM`, `UTF-16 LE`, `UTF-16 BE`, and `ISO-8859-1` (`Latin-1`) with `files.autoGuessEncoding` (`ReadFilePreservingMetadata` / `WriteFilePreservingMetadataLossless`), preserves `CRLF`/`LF` with status bar EOL toggling and `files.eol` for new files (`ToggleActiveTabEol`), and applies `files.insertFinalNewline` and `files.trimTrailingWhitespace` via `SaveActions.ApplyToBuffer`.
- **Large & binary file safety**: Opens files >= `files.maxMemoryForLargeFilesMB` (default 50 MB, `LargeFilePolicy`) in the paged read-only viewer (`AvaloniaLargeFileViewer` / `WinFormsLargeFileViewer`), disables expensive TextMate regex tokenization and bracket scans on lines `> 20,000` characters (`EditorSyntaxSession.IsTooLongForTextMate`), and displays a binary warning placeholder with `"Open Anyway"` (`ShowBinaryPlaceholder` / `OpenBinaryFileAnyway`).

- **Shared immutable themes & bitmaps (`SharedImmutableThemesAndIcons_ZeroDuplicateAllocations`)**: Cached built-in `StudioTheme` instances (`0 B` allocated across 50 `StudioTheme.GetById` lookups vs. `1,994,000 B` before) and shared window icons/welcome bitmaps across windows.
- **Post-`W4` feature memory guard (`W12`, `docs/MEMORY.md` §6, `NewFeatures_IdleTimersStopped_AndPostCloseHeapWithinW4Budget`, `OpenAndCloseFiveWindows_LeaksNothing_WeakReferences`)**: Verifies that with `files.hotExit`, `codeless.mcp`, `.codeless/{agent,command}` mtime cache, `@file` completer, and `W7`/`W10` features enabled, `IsHotExitTimerRunning` and all background timers stop when idle, zero MCP processes spawn before first use, single-window post-close delta stays at **`+3.95 MB`** (`< 8.0 MB` budget), and opening/closing 5 workspace windows collects `5/5` `MainWindow`s and `5/5` `EditorTabBuffer`s.

# codeLess v3.3.5

A focused update for the terminal, and the first version you can install from inside codeLess
(**Help → Check for Updates…**, or the codeLess menu on macOS).

## Fixed

- **Pasting into full-screen terminal apps** (e.g. the Antigravity CLI `agy`, other Bubble Tea / Ink apps): codeLess now
  answers the terminal capability questions these apps ask at startup (device attributes, terminal version, foreground /
  background colour), exactly like VS Code's terminal. Without the answers some apps waited and didn't take input.
- **Edit → Paste / Copy / Select All with the terminal focused** (also ⌘V / ⌘C through the macOS menu) now go straight
  to the focused terminal, including split terminals.

## Trust and verification

Releases include GitHub build-provenance attestations and a Sigstore-signed `SHA256SUMS.txt`; Linux packages are also
OpenPGP-signed (`docs/codeLess-release-signing-key.asc`). See `docs/SIGNING.md`.

## Upgrade notes

- From v3.3.4+: Help → Check for Updates… downloads, verifies and installs this version. From v3.3.3 or older, download
  it once by hand.
- Windows SmartScreen and macOS Gatekeeper may still warn until code-signing certificates are in place.
