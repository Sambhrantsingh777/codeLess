Bundled TextMate grammars (gzip-compressed JSON, embedded in codeLess.Core as resources)
=========================================================================================

Only MIT-licensed grammars are bundled. Each file is the JSON conversion shipped in the MIT-licensed
VS Code repository (microsoft/vscode, extensions/*/syntaxes), re-serialized without whitespace and gzipped.
