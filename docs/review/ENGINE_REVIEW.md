# Shared engine review (codeLess.Core + UI integration)

Reviewer: independent read-through of `main` at `607b409` (the QA-fixes merge). Scope: the LSP, DAP, Git, Tasks, network/privacy,
agent-trust, large-file/workspace and extension engines in `src/codeLess.Core`, the shared files under `src/`, and how
`src/codeLess.Avalonia/MainWindow.*.cs` and the WinForms partials call them.

Method: I read the code by hand. The findings marked **[repro]** were confirmed with a throwaway console program that referenced
`codeLess.Core` (net8.0, run on macOS/APFS). I deleted that program afterwards and did not change any product code.
Confidence: **H** = confirmed by repro or an unambiguous code path. **M** = I'm sure the code does this, but the impact depends on the
environment or the server. **L** = plausible, still needs a check on the target platform.

Severity: **critical** = silent data loss or code execution with no user action. **high** = data loss / security / privacy promise
broken through a normal workflow. **medium** = wrong behaviour users will hit, or a resource leak. **low** = edge case or parity nit.

## Summary of the top issues

1. **Replace All in Find-in-Files changes text the preview never showed.** Search matches line by line, but Replace runs one
   Multiline regex over the whole file. Any `\s`, `[^…]` or `\W` can then match across a newline and join lines.
2. **Opening a source file in an untrusted folder can run code from that folder.** `node_modules/.bin`, `.venv/bin`, `venv/bin`,
   `env/bin` and `.env/bin` of the workspace are searched *before* PATH when looking for a language server.
3. **An LSP case-only rename with `overwrite:true` deletes the file** on Windows/macOS. Without `overwrite` the rename just fails.
4. **LSP workspace edits to closed files corrupt non-UTF-8 files.** Every Latin-1 / ANSI byte is rewritten as U+FFFD.
5. **Offline Mode can be bypassed by an HTTP redirect.** Only the first URL is checked. Redirect targets are followed silently and
   never appear in the Network ledger.
6. **Loading an extension from a folder can write outside the extensions directory.** `version`/`name` from `package.json` are
   not sanitized.
7. **Language-server process leaks** when a restart or workspace switch races with a server that is still starting.
8. **jdtls gets a new `-data` folder on every launch on macOS/Linux** (`string.GetHashCode` is randomized on .NET 8). It reindexes
   every time and leaves GBs behind in temp.
9. **Task `dependsOn` chains can stop silently**, and `preLaunchTask` is ignored (debugging a stale build).
10. **The agent "temporary copy" is not fully isolated.** Dependency folders are symlinked to the real ones, and git refs and the
    stash are shared with the user's repo.
